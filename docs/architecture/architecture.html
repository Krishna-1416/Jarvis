PIPELINE 02

Deterministic Routing & Tool Safety Gate

Fast-path regex routing bypasses LLM latency for system controls. For complex actions, Jarvis generates typed JSON tool calls validated through a strict confirmation gate before operating system modification. 

flowchart TD

    Classify -->|Volume / Media / Launch App| FastPath[0ms Fast-Path Router]
    Classify -->|Reasoning / Email / Web / Complex| LocalRoute[Local Brain: Qwen 3.5 4B]
    
    FastPath --> ExecTool[Execute Windows Tool Handler]
    
    subgraph Local_Inference [Local Inference Engine]
        LocalRoute --> GenToolCall[Generate JSON Tool Call]
        GenToolCall --> ValidateSchema{Valid Schema?}
        ValidateSchema -->|Yes| SafetyGate{Destructive Action?
format, delete, registry}
        ValidateSchema -->|Malformed| Retry[Self-Correction Loop]
        Retry --> LocalRoute
    end
    
    SafetyGate -->|Yes| PromptUser[Prompt User Vocal/Click Confirmation]
    SafetyGate -->|No / Safe| ExecTool
    PromptUser -->|Confirmed| ExecTool
    PromptUser -->|Denied| CancelTool[Abort & Return Notice]

SUBSYSTEMS

Architectural Pillars

Six modular subsystems decouple input capture, inference, state management, and operating system execution.

01 / AUDIO
Sub-100ms Silero VAD
Runs continuously on CPU to segment incoming mic audio into discrete speech packets while filtering ambient keyboard clatter and fan noise.
02 / INFERENCE
Quantized Faster-Whisper
Employs CTranslate2 int8 quantization on CUDA cores to deliver accurate speech-to-text transcriptions with under 150ms processing latency.
03 / ROUTING
Deterministic Intent Bypass
Bypasses LLM token generation entirely for media keys, volume control, and app launching, executing instantly in sub-10ms.
04 / MEMORY
Dual Episodic & Vector Store
A local SQLite database retains historical context while MiniLM vector embeddings dynamically surface user preferences and previous facts.
05 / SYNTHESIS
Kokoro-82M Neural Audio
Synthesizes natural British-English speech via CPU ONNX runtime in streaming audio chunks, supporting instant voice barge-in cancellation.
06 / INTERFACE
Translucent PyQt6 HUD
A borderless, resizable Windows desktop widget with animated Arc Reactor visualizer, tray daemon, and zero focus-stealing behavior.
