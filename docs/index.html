🤖 Project Jarvis

Personal AI Desktop Assistant for Windows

Project Jarvis is a localized, privacy-first desktop assistant featuring offline voice interaction, a futuristic Arc Reactor HUD, and optional Google Workspace integrations.

Key Capabilities

  • Real-time voice activity detection (VAD) and speech recognition.
  • Local offline language model processing via Ollama.
  • Zero-latency system control (volume, brightness, application launching).
  • Gmail assistant integration for hands-free inbox summaries.

Privacy & Open Source

Jarvis runs 100% locally on your personal computer. All authentication tokens and email contents remain strictly on your local device and are never sent to external servers.
